Kebijakan Privasi & Integritas Ujian

Selamat datang di ExaGuard Pro. Demi kenyamanan, keamanan, dan keadilan bersama selama pelaksanaan ujian, harap baca dan setujui ketentuan kebijakan berikut:

1. Pemantauan Keamanan Ujian (Proctoring)
Aplikasi ini menggunakan teknologi pelacakan browser secara real-time. Sistem akan mendeteksi dan mencatat riwayat jika Anda berpindah tab browser, meminimalkan layar, membuka aplikasi lain, atau keluar dari mode layar penuh (fullscreen).

2. Pembatasan Input Pengguna
Fitur klik-kanan (context menu), salin-tempel (copy-paste), pengambilan gambar layar lewat print, serta shortcut developer tools (F12) dinonaktifkan secara otomatis untuk mencegah penyebaran soal.

3. Penyimpanan Data Lokal
Data pribadi Anda (Nama, NIS), rincian jawaban, dan riwayat aktivitas pelanggaran keamanan akan disimpan dalam basis data browser lokal dan dilaporkan langsung pada Dashboard Pengawas untuk proses penilaian.

4. Pernyataan Integritas Ujian
Dengan melanjutkan, Anda berjanji akan mengerjakan ujian ini dengan jujur secara mandiri tanpa bantuan pihak luar, catatan fisik, maupun referensi online lainnya.
